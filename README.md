# 3軸を１つのデフォーマで表現する場合 - 挙動確認プレビュー
このWebアプリケーションは、Live2Dモデリングや一般的な3D回転表現において、3軸の回転を1つのデフォーマ（またはパラメータ）で制御する際の、各軸の組み合わせによる挙動を確認するために開発されました。
特に、ジンバルロックを防ぎ、シームレスな360度ループを実現するためのキー設定や、Z軸オフセットの視覚的な影響を、リアルタイムな3Dキューブで確認できます。

## 🚀 主な機能
3軸シームレスループ: X軸、Y軸、Z軸の各角度（$-180, -90, 0, 90, 180$）の組み合わせを選択し、カード（キューブ）の回転挙動をプレビューします。
Z軸オフセットの検証: Z軸の値が、他の軸（特にX軸）の回転にどのように影響を与えるかを視覚的に確認できます。
ルックアップ結果の表示: 現在のX, Y, Zの値の組み合わせが、モデル上で「表」「裏」「側面」のどの状態に対応するかをリアルタイムで表示します。
多言語対応: 日本語（JP）と英語（EN）の表示切り替えに対応しています。

## ⚙️ 使い方
GitHub Pagesなど、このリポジトリをホストしているURLにアクセスします。
「X」「Y」「Z」の各行にあるボタンをクリックして、軸の回転角度を選択します。
画面右側の「プレビュー」エリアで、選択した角度によるカードの3D回転と、その結果（「プレビューの動きの名前」）を確認します。
特に**側面（Side）**が表示される組み合わせや、Z軸が影響を与えるケースを重点的に確認することで、Live2Dでのキー設定の精度を向上させることができます。

## 💡 Live2Dモデラー向けヒント
Live2Dにおいて、3軸を1つのデフォーマで実現する際には、デフォーマを入れ子にしたり、特定の位置（例：$X=\pm 90^\circ$）でキーを打ち込む必要があります。このツールは、どのパラメータの組み合わせが「側面」や「裏」に対応するかのルックアップテーブルとして役立ちます。
